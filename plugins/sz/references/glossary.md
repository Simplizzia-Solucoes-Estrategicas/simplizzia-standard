# Base glossary

Business term as the team says it → name in code. One code name per concept; the last column lists forbidden synonyms. Project-specific terms go in the project's `CLAUDE.md` in the same format. A term missing here: ask the user what it means, pick one English name, and add it to the project's glossary in the same change.

|---|---|---|

| funcionário, colaborador | employee | worker, staff |
| fornecedor | supplier | vendor, provider |
| orçamento | quote | budget, estimate |
| pedido | order | request, purchase |

| cobrança | charge | billing, payment request |
| pagamento | payment | transaction |
